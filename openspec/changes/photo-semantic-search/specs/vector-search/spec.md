# vector-search 规格（双路召回与重排增量）

## ADDED Requirements

### Requirement: 图片双路召回

图片模态检索 SHALL 支持双路召回：查询文本同时经 CLIP 文本编码器（像素语义路，对图片像素向量空间检索）与文本嵌入模型（描述文本路，对图片标注文本向量空间检索），两路结果按倒数排序融合（RRF）合并。任一路无候选时 MUST 退化为单路直通且不报错；两路均无候选时返回空结果。空间隔离纪律沿既有要求：各路只在自身 (模态, 模型) 空间内比较。

#### Scenario: 双路命中融合

- **WHEN** 库内存在标注为"红色的小花"的照片，用户查询"红色的小花"（图片模态）
- **THEN** 该照片经描述文本路命中，与像素路命中按 RRF 融合排序返回

#### Scenario: 存量无标注图片单路可用

- **WHEN** 库内图片均无标注（描述路空间为空），用户发起图片模态检索
- **THEN** 检索退化为像素路单路直通，正常返回结果

### Requirement: 召回后重排阶段

图片模态检索 SHALL 在召回融合之后提供重排阶段：对融合后 topK 候选，以交叉编码器对「查询 × 候选图片标注文本（主题+描述）」打分，按重排分数重排取 topN 返回。重排 MUST 仅作用于有标注文本的候选；无标注文本的候选 MUST NOT 参与文本重排（保留召回序位或排除，行为需确定且响应标注）。重排后响应 MUST 携带重排分数与 `reranked=true` 标志。

#### Scenario: 重排改变排序

- **WHEN** 召回 topK 中某候选的标注文本与查询语义高度相关但召回序位靠后
- **THEN** 重排后该候选序位上升，响应携带其重排分数与 reranked=true

#### Scenario: 全部候选无标注时重排直通

- **WHEN** 召回候选均无标注文本（或重排器不可用）
- **THEN** 结果保持召回序位，响应携带 reranked=false 与原因标注，不报错

### Requirement: 重排的候选上限与降级开关

检索端点 SHALL 接受可选参数控制是否启用重排（缺省启用）与重排候选数上限（有服务端默认值与硬上限）。重排器不可用、候选超限或标注缺失时按降级语义执行（直通+标注），MUST NOT 使检索请求失败。

#### Scenario: 显式关闭重排

- **WHEN** 客户端请求参数关闭重排
- **THEN** 返回召回融合结果，reranked=false，耗时不含重排

#### Scenario: 重排器故障不致检索失败

- **WHEN** Python 引擎重排操作持续报错，用户发起启用重排的检索
- **THEN** 检索返回召回结果与 reranked=false 及降级原因

### Requirement: 检索响应的标注透出

图片模态检索的命中项 SHALL 携带：召回各路分数、融合序位、重排分数（如参与）、图片标注摘要（subject / description / mocked）与图片访问端点。既有响应字段 MUST 保持不变（向后兼容）。

#### Scenario: 命中项字段完整

- **WHEN** 图片模态检索命中一张已标注照片
- **THEN** 命中项含 subject、description、mocked 标志、相似度分数与图片 URL，可直接渲染
