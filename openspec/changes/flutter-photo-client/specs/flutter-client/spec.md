# flutter-client 规格（Flutter 照片客户端）

## Purpose

为照片语义检索后端提供移动端原生客户端：以成熟商业应用（美团/淘宝/京东）的信息架构范式组织完整页面体系与跳转交互，覆盖照片浏览、批量上传、语义搜索与大图预览，并以演示数据模式支持后端就绪前全流程可跑。

## ADDED Requirements

### Requirement: 底部五槽导航架构

客户端 SHALL 采用底部五槽导航（首页 / 相册 / 中央凸起上传按钮 / 搜索 / 我的）：中央按钮为上传入口（视觉凸起），其余四槽为 Tab 页；Tab 切换 MUST 保留各页状态与滚动位置；任何页面 MUST 可经不多于一次返回回到主导航壳。

#### Scenario: Tab 切换保状态

- **WHEN** 用户在相册页滚动到中部后切到首页再切回相册
- **THEN** 相册页保持原滚动位置与已加载数据，不重新初始化

#### Scenario: 中央上传入口

- **WHEN** 用户点击底部中央凸起按钮
- **THEN** 以上传页为主全屏流程进入，可返回主导航壳

### Requirement: 首页信息架构

首页 SHALL 由三段构成（自上而下）：胶囊搜索栏（点击进入搜索页）、功能宫格（至少含全部照片 / 最近上传 / 批量导入 / 模拟识别 / 未拆分入口）、照片瀑布流卡片区（双列，卡片含缩略图 / 主题 / 描述 / mocked 徽标）。宫格入口 MUST 携带对应筛选参数跳转至相册或上传页，不得呈现无行为入口。

#### Scenario: 搜索栏进入搜索页

- **WHEN** 用户点击首页顶部搜索栏
- **THEN** 跳转搜索页且输入框获得焦点

#### Scenario: 宫格带参跳转

- **WHEN** 用户点击"模拟识别"宫格
- **THEN** 相册页以 mocked=true 筛选态打开并展示对应照片

#### Scenario: 瀑布流卡片信息完整

- **WHEN** 首页照片流加载一张已标注照片
- **THEN** 卡片展示缩略图、主题、描述与 mocked 徽标（如适用）

### Requirement: 相册页视图与筛选

相册页 SHALL 支持网格（三列）与瀑布流（双列）视图切换（选择持久记忆），并提供标注状态筛选（全部 / 已标注 / 模拟识别 / 未拆分）；下拉刷新与滚动分页加载 MUST 可用，分页追加无重复项。

#### Scenario: 视图切换持久

- **WHEN** 用户切为三列网格后退出重进相册页
- **THEN** 相册仍为网格视图

#### Scenario: 筛选联动数据

- **WHEN** 用户筛选"未拆分"
- **THEN** 列表仅含无标注照片

#### Scenario: 分页追加无重复

- **WHEN** 照片数超过单页且用户滚动到底
- **THEN** 追加下一页且不出现重复卡片

### Requirement: 语义搜索页

搜索页 SHALL 提供：搜索输入与提交（调用图片模态检索、重排默认开启）、搜索历史（本地持久化、可清空）与推荐查询词；结果以瀑布流命中卡片展示（缩略图、描述、相似度或重排分数的可视化、mocked 徽标）。检索失败 MUST 展示错误态与重试入口；空结果与错误态 MUST 视觉区分；「加深搜索」MUST 以更高候选数重新检索。

#### Scenario: 模糊查询命中

- **WHEN** 用户查询"红色的小花"且数据源含标注为该描述的照片
- **THEN** 结果按相关性排序展示该照片，卡片含描述与分数可视化

#### Scenario: 搜索历史

- **WHEN** 用户完成一次查询后重进搜索页
- **THEN** 历史区展示该查询词，点击即以该词发起检索

#### Scenario: 后端错误态

- **WHEN** 检索请求失败（网络或服务端错误）
- **THEN** 搜索页展示错误提示与重试按钮，不渲染误导性空态

### Requirement: 大图预览页

命中卡片与相册卡片 SHALL 经共享元素过渡（Hero）进入全屏预览：原图展示、底部可展开标注面板（主题 / 描述 / 标签 / 相似度与重排分数），左右滑动 MUST 可切换同列表内相邻照片。

#### Scenario: Hero 进入预览

- **WHEN** 用户点击某照片卡片
- **THEN** 卡片缩略图以连续动画放大为全屏原图

#### Scenario: 滑动切换相邻

- **WHEN** 预览态下用户左滑
- **THEN** 切换到结果列表中的下一张照片，标注面板同步更新

### Requirement: 批量上传流程

上传页 SHALL 提供：系统相册多选 → 已选照片管理（横向滚动、可移除）→ 共享描述输入（可空，作为 caption）→ 提交至批量端点 → 进度展示（已处理 / 总数 / 成功 / 失败）→ 失败明细（文件名+原因）与画廊刷新。单批超出后端上限时客户端 MUST 自动分批串行提交并呈现为连续进度。

#### Scenario: 多选上传进度可见

- **WHEN** 用户多选 30 张照片提交上传
- **THEN** 进度页展示已处理数递增至 30，完成后画廊可见新照片

#### Scenario: 自动分批

- **WHEN** 所选照片数超过后端单请求上限
- **THEN** 客户端自动拆批串行提交，进度连续呈现

#### Scenario: 部分失败明细

- **WHEN** 导入完成且存在失败文件
- **THEN** 完成态列出失败文件名与原因

### Requirement: 我的页与后端配置

「我的」页 SHALL 展示照片统计卡（总数 / 已标注 / 模拟识别 / 未拆分计数）与设置项：后端地址编辑（保存即生效）、连接自检（调用健康端点并展示结果）、演示模式开关、关于信息。地址不可达或自检失败 MUST 明确提示且不崩溃。

#### Scenario: 统计卡与数据源一致

- **WHEN** 数据源加载完成进入我的页
- **THEN** 四项计数与当前数据源实际数据一致

#### Scenario: 切换后端地址

- **WHEN** 用户将后端地址改为局域网 IP 并保存
- **THEN** 后续请求指向新地址，自检显示连通结果

### Requirement: 演示数据模式

客户端 SHALL 内置演示数据源（PhotoRepository 的本地实现）：确定性生成的占位图与固定标注样例（含"红色的小花"等演示语义、含 mocked=true 与未拆分样本），支撑首页 / 相册 / 搜索（含相关性排序样例）/ 预览全流程零后端运行。演示模式 MUST 显式标识（页面横幅或统一徽标），开关位于我的页；切换数据源时各页 MUST 即时刷新。演示模式下的上传流程 MUST 以本地模拟任务呈现进度语义（不产生真实入库），并明示"演示"。

#### Scenario: 零后端全流程

- **WHEN** 后端不可用且演示模式开启，用户浏览首页、相册并搜索"红色的小花"
- **THEN** 各页正常渲染演示数据，搜索返回演示样例的排序命中，全程无网络错误提示

#### Scenario: 演示模式显式标识

- **WHEN** 演示模式开启
- **THEN** 页面可见"演示数据"横幅或徽标，上传完成态明示未真实入库

#### Scenario: 数据源切换即时生效

- **WHEN** 用户在我的页关闭演示模式
- **THEN** 首页/相册/搜索立即以真实 API 数据刷新，不再展示演示标识
