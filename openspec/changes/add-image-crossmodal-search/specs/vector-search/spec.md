# vector-search 规格（图片跨模态检索增量）

## ADDED Requirements

### Requirement: 跨模态文本搜图

系统 SHALL 支持以自然语言文本查询检索图片资源：查询文本 MUST 经与图片向量同一模型（CLIP 文本编码器）编码后，对 IMAGE 模态向量做余弦相似度 topK。检索响应 SHALL 携带命中图片的资源标识、相似度分数与模态标注。

#### Scenario: 文本查询命中相关照片

- **WHEN** 图片库已摄取含"红塔"的照片，用户以图片模态检索"红塔"
- **THEN** 返回按相似度降序排列的命中照片列表，每条含资源标识与相似度分数

#### Scenario: 图片库为空时返回空结果

- **WHEN** 尚未摄取任何图片时用户以图片模态检索
- **THEN** 返回空命中列表与正常响应，不报错

### Requirement: 向量空间隔离

向量索引与检索 SHALL 按 (模态, 模型) 分组隔离。不同空间的向量即使维度相同（如 512 维文本向量与 512 维 CLIP 向量）MUST NOT 参与同一次相似度计算；查询 MUST 只在与其编码器对应的目标空间内进行。

#### Scenario: 同维度跨空间不污染

- **WHEN** 库内同时存在 bge 文本向量（512 维）与 CLIP 图片向量（512 维），用户发起任一模态的检索
- **THEN** 文本检索的候选集不含图片向量，图片检索的候选集不含文本向量

#### Scenario: 空间不匹配被明确拦截

- **WHEN** 查询向量与目标分组空间不一致（模态或模型不对应）
- **THEN** 系统拒绝该比较并返回明确错误，而非返回错误结果

### Requirement: 检索模态参数与向后兼容

检索端点 SHALL 接受模态参数（text / image），缺省为 text。缺省模态下的请求与响应行为 MUST 与既有文本检索完全一致（既有客户端零改动）。

#### Scenario: 缺省模态保持既有行为

- **WHEN** 客户端按既有方式调用检索端点（不带模态参数）
- **THEN** 行为与响应结构与文本检索现状完全一致

#### Scenario: 指定图片模态走跨模态路径

- **WHEN** 客户端以模态参数 image 调用检索端点
- **THEN** 查询经 CLIP 文本编码器编码，仅对 IMAGE 向量检索

### Requirement: 图片模态检索仅语义路

图片模态的检索 SHALL 仅使用向量语义路径，MUST NOT 调用全文索引路径；融合逻辑 SHALL 适应单路径输入（不因缺少全文命中而失败）。

#### Scenario: 图片检索不产生全文命中

- **WHEN** 用户以图片模态检索任意查询词
- **THEN** 响应仅含语义路径命中，无全文路径结果，检索正常完成

### Requirement: 图片检索的耗时与降级透出

图片模态检索响应 SHALL 携带耗时与 degraded 标志，语义与文本检索一致；CLIP 处于降级模式时命中结果的语义精度受限提示 MUST 透出给调用方。

#### Scenario: 降级模式下的图片检索

- **WHEN** CLIP 引擎处于哈希降级模式时用户以图片模态检索
- **THEN** 响应标记 degraded=true，前端可据此提示精度受限
